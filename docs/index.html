Packed with Features

Everything you need to stay on top of your medication schedule and health goals.

🔐

Secure Authentication

Firebase-powered login and registration with email/password. Includes password reset and friendly error messages for every scenario.

⏰

Smart Reminders

Set multiple daily reminder times for each medicine. Exact alarms ensure you're notified on time, even with the app closed.

📊

Adherence Tracking

Real-time adherence score shows your taken vs. missed dose percentage. Stay motivated and accountable every day.

📦

Stock Management

Track your medicine inventory with automatic low-stock and out-of-stock alerts. Never run out unexpectedly again.

📅

Calendar History

Beautiful calendar view to browse your dose history day-by-day. See exactly what you took and what you missed.

👨‍👩‍👧

Caregiver Mode

Share your unique code with family members so they can monitor your medication adherence remotely. Peace of mind for everyone.

Get Started in 3 Steps

Clone, configure Firebase, and run — it's that simple.

1

Clone the Repo

Download the source code from GitHub to your local machine.

git clone https://github.com/vaibhavraj082007/MediReminder3.git
2

Setup Firebase

Create a Firebase project, add your Android app, download google-services.json and enable Email/Password auth.

3

Build & Run

Open in Android Studio, let Gradle sync, connect a device or emulator, and hit Run!
